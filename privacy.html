Privacy Policy

Effective 18 October 2026

shorts-uploader ("the tool") is a personal command-line tool. Its only user is its owner. It uploads and schedules videos on the owner's own YouTube channel and Facebook Page. This policy explains what data the tool accesses, where that data is kept, and how to remove it.

YouTube API Services

The tool uses YouTube API Services. By using the tool you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

What data the tool accesses

  • Google / YouTube: an OAuth sign-in token for the owner's Google account, with permission to upload and manage videos. The tool also reads the owner's own channel and its recent uploads (video IDs, titles and privacy status), so that it never uploads the same video twice.
  • Meta / Facebook: an access token for the owner's own Facebook Page, used to publish and schedule Reels. The tool also reads that Page's recent Reels (IDs and captions), for the same duplicate check.

The tool does not access, collect or store data about any other person: no viewers, commenters, subscribers or analytics.

How the data is used and stored

  • Data is used only to upload, schedule and keep track of the owner's own videos.
  • Everything is stored locally on the owner's computer. The tool has no server and no database, and sends no data anywhere except to Google and Meta, through their official APIs.
  • Nothing is sold, shared with third parties or used for advertising.
  • The tool sets no cookies, and this website uses no cookies or tracking.

Revoking access

  • Google: remove the app's access at myaccount.google.com/permissions. See also Google security settings.
  • Facebook: remove the app in Facebook Settings & privacy → Settings → Business integrations (or Apps and websites).

Data deletion

The tokens are deleted by deleting the local files that hold them, and revoking access as described above makes them useless straight away. The records of the owner's own video IDs are deleted by deleting the project folder. Deleting data from the tool does not delete any video from YouTube or Facebook; that is done in YouTube Studio or on the Page. To ask about deletion, email the address below. Requests are answered within 7 days.
